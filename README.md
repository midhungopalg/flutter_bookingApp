# registration_app

Flutter **course booking** demo: home banners, selectable course carousel, and registration POST to external APIs.

**New to Flutter?** Read the step-by-step guide: [FLUTTER_BEGINNER_GUIDE.md](FLUTTER_BEGINNER_GUIDE.md)

## Getting Started

```bash
flutter pub get
flutter run
```

API configuration: `lib/config/api_config.dart`
